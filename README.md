# Gargantua · 黑洞模拟

《星际穿越》卡冈图雅风格的黑洞实时渲染。基于 three.js + 全屏光线步进着色器，
按史瓦西时空零测地线方程对每像素做反向光线追踪。

## 运行

```bash
npm install        # 仅依赖 three
npm start          # http://localhost:8642
```

任意静态服务器均可（模块加载需要 http 协议，不能直接双击 html）。

## 效果

- **引力透镜**：光线按测地线方程 `p'' = -(3/2)·rs·h²·p/r⁵` 弯曲，星场、爱因斯坦环、
  吸积盘的天顶/底部包裹像都是真实弯曲结果
- **吸积盘**：程序化剪切湍流纹理、差速自转（内快外慢）、黑体式色带、
  多普勒增亮（接近侧亮且偏蓝）、引力红移内缘衰减
- **星空**：程序化生成的等距柱状星图（恒星 + 银河带 + 尘埃暗带）

## 操作

- 鼠标拖拽旋转，滚轮缩放，`H` 键隐藏面板
- 侧栏实时调节：质量（史瓦西半径）、盘内外半径、亮度、色温、多普勒强度、
  不透明度、转速、曝光、星空亮度、辉光、光线步进数、渲染分辨率、视场角

## 性能

默认 80% 分辨率 × 256 步进。卡顿可下调"渲染分辨率"或"光线步进数"；
机器强劲可拉满到 100% / 384 步获得更锐利的临界光环。
